The Yacht Club of Hyderabad — Brand Assets
================================================
Tagline: DIGNITY THROUGH SPORTS

FOLDER CONTENTS
---------------
* yc-logo-master.png            — full-resolution V1 with tagline (RGBA, white bg)
* yc-logo-3x-print.png          — 3x upscaled for very large prints (A2 / banners)
* yc-logo-1600.png / .jpg       — high-resolution web / presentation
* yc-logo-1080.png / .jpg       — standard web / social media
* yc-logo-512.png               — small web / Slack / Discord avatar
* yc-logo-master-transparent.png — transparent background, full-res
* yc-logo-1080-transparent.png   — transparent background, web size
* yc-logo.pdf                   — vector-quality, print-ready (300 DPI)
* favicon.ico                   — multi-size .ico (16/32/48/64/128/256)
* favicon-16.png … favicon-512.png — square sailboat icon at various sizes
* apple-touch-icon.png          — 180×180 for iOS home-screen

USAGE TIPS
----------
* Web / browser tab        → favicon.ico  +  favicon-32.png
* Android / PWA            → favicon-192.png  /  favicon-512.png
* iPhone home-screen       → apple-touch-icon.png
* Social profile picture   → favicon-512.png  or  yc-logo-1080.jpg
* Print (letterhead)       → yc-logo.pdf  or  yc-logo-master.png
* Large prints (A2 / A1)   → yc-logo-3x-print.png
* Email signatures         → yc-logo-512.png
* Dark backgrounds         → yc-logo-master-transparent.png
